AI GOVERNANCE DEPARTMENT (PUBLIC DEMO) - START HERE
Version 2.0, October 2026 (aligned to the Hourglass Model 2026 edition)

This folder holds 5 of the 16 agents of the AI Governance Department, the templates they use, the Context File and the project instructions. Agents may hand off to agents that are only in the full version; skip those steps or do them by hand.

SETUP
1. Create a new Project (for example in Claude) called "AI Governance Department".
2. Upload every file in this folder to the Project knowledge.
3. Fill in "AI Governance Context File" first. Every agent reads it.
4. Paste "01 PROJECT INSTRUCTIONS" into the Project's custom instructions.
5. Run an agent: "Run AIG 07 Mode A for this system: [notes]."

See the repository README for the full architecture.
