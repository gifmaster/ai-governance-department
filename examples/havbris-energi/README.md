# Test case: Havbris Energi A/S (fictional)

Havbris Energi A/S is a made-up Danish electricity and heat retailer with about 140 employees and 60,000 household customers. Customer service wants to buy an AI chatbot, "KundeAssist", from a vendor called ChatNordic ApS. Everything here is invented: the company, the people, the vendor and the data.

Use it to see how the five public agents behave on messy, realistic input.

## How to run it

1. Set up the department as described in the main README.
2. Upload `context-file-havbris.md` as the Context File, plus files `01` to `06` from this folder.
3. Do **not** upload `TEST-SCRIPT.md`. It is the answer key.
4. Run the steps in `TEST-SCRIPT.md` one by one and compare the output with the "Pass if" criteria.

## Files

| File | What it is |
|---|---|
| `context-file-havbris.md` | The filled Context File |
| `01-use-case-idea.md` | The head of customer service's email proposing the chatbot |
| `02-vendor-fact-sheet.md` | ChatNordic's marketing fact sheet |
| `03-system-notes.md` | Internal notes from the pilot |
| `04-committee-minutes.md` | Minutes from the AI committee meeting |
| `05-monitoring-log.csv` | Eight weeks of pilot metrics |
| `06-incident-raw.md` | A complaint that came in during the pilot |
